## Assigned Direction: Trading Ticket Book (Raised)

### Thesis
Each project is a trading ticket — carbon copy, ruled fields, stamped states, immutable once written. The dashboard is a settlement ledger where optimization = stamping `SETTLED` on the portfolio total.

### World (Raised)
- **Palette/Material**: Cream coupon stock (`#F5F0E8`), carbon purple (`#4A3A5A`) for filled fields, carrier navy (`#0B1D3A`) for headers, VOID red (`#C0392B`) for rejected, verified green (`#27AE60`) for accepted. Subtle paper texture.
- **Type/Composition**: `Space Grotesk` for headers (caps, tracked), `JetBrains Mono` for fields. Each ticket = one row = one project. Ruled grid with carbon-copy lines between tickets.
- **Topology/Navigation**: **HARD FOCUS SPLIT** (donor: Cassette J-Card) — two persistent panes: Parameters (left, 380px) and Results (right, flex). Model selector as "spine" between panes. No tabs.
- **Controls/State**: Whitelist = `☑` green stamp. Blacklist = `☒` red VOID. Rating filter = perforated dropdown. Project cap = filled field. **PLAIN-LANGUAGE LABELS** (donor: Warm Consumer App): "Max per Project", "Concentration Limit", "Developer Weight".
- **Responsive/Motion**: Tablet stacks panes vertically with spine as toggle. Mobile same. **LIVE CONSTRAINT SLIDERS** (donor: Variable Font Specimen) — dragging C_max/α weights remaps ticket ledger in real time with live stamp updates. **REGISTERED COMPARATIVE PLATES** (donor: Botanical Folio) — comparison view = five aligned plates (Baseline | Corr Budget | Time-Aware | Stress | Delta) with identical row order, cross-fade at fixed position. **TERRAIN HEATMAP BACKGROUND** (donor: Orienteering Map) — subtle HHI tint behind country/developer cells in ledger.

### Signature Move
**Stamp confirmation** — when optimization completes, a `SETTLED` stamp in green ink lands on the portfolio total row with subtle press animation. Audit trail visible as carbon-copy duplicates in history drawer.

### Cross-Surface Reach
- **Parameters pane** → reusable filter/control stack for any Operate surface
- **Ticket ledger** → virtualized table component with stamp states, carbon rules
- **Comparative plates** → five-panel registered overlay system for any model comparison
- **Spine navigation** → persistent model selector pattern

### Honest Risk
The carbon-copy metaphor risks feeling "costumey" if the paper texture, stamps, and ruled lines aren't restrained to pure information design. The raised comparative plates and live sliders pull toward Quant Dashboard Terminal territory — must keep the ticket grammar (ruled fields, stamps, carbon lines) as the organizing principle, not the Quant grid.

## Challenger Verdicts

### 1. Variable Font Specimen — COMPETITIVE
**Holds**: Product clarity (live remapping = visible optimization landscape)
**Loses**: Audience identification (type specimen tool ≠ trading tool)
**Kept by direction**: Live constraint sliders (C_max, α weights drag → live ticket remap)
**Raise**: *Live constraint slider* — donor: Variable Font Specimen

### 2. Warm Consumer App Surface — DECLINED
**Loses both**: Consumer thumb-driven aesthetic misreads desktop density context; card-per-ticket impossible at 4,355 projects
**Kept by direction**: Plain-language field labels ("Max per Project", "Concentration Limit")
**Raise**: *Plain-language field labels* — donor: Warm Consumer App Surface

### 3. Orienteering Map — DECLINED
**Loses both**: Portfolio managers scan tables, not terrain; optimization changes terrain (wrong metaphor)
**Kept by direction**: Terrain heatmap background — subtle HHI tint behind country/developer cells
**Raise**: *Terrain heatmap background* — donor: Orienteering Map

### 4. Botanical Folio — WINS (beats assigned on both axes)
**Beats assigned**: Fixed-scale registered plates = exact comparative analysis need; structural honesty exceeds ticket book's single-view metaphor
**Kept by direction**: Registered comparative plates — five aligned plates (Baseline | Corr Budget | Time-Aware | Stress | Delta), cross-fade at fixed position
**Raise**: *Registered comparative plates* — donor: Botanical Folio

### 5. Cassette J-Card — COMPETITIVE
**Holds**: Product clarity (hard focus split = enforced parameter→result workflow)
**Loses**: Audience identification (vernacular ballpoint aesthetic misreads precision audience)
**Kept by direction**: Hard focus split — two persistent panes (Parameters | Results) with model selector as spine
**Raise**: *Hard focus split* — donor: Cassette J-Card

### 6. Streaming Title Card Wall — DECLINED
**Loses both**: Horizontal rails = factors, tiles = groups works for concentration overview but fails portfolio ticket detail; focus-expand is mobile pattern, not desktop density
**Kept by direction**: Rail metaphor for concentration factors (kept as heatmap background rows)
**Raise**: *Factor rails as heatmap rows* — donor: Streaming Title Card Wall
